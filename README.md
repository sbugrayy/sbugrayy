### 👋 About me

I'm a **backend developer** who builds the APIs and services behind products — and lately, the AI that runs inside them: RAG pipelines, LLM agents and computer vision models.

- 🔭 Currently building an **ASP.NET Core Web API** for a finance & invoicing app *(internship)*
- 🧠 I ship **RAG** systems and **MCP** servers, and fine-tune my own models when an external API isn't the right fit
- 🏆 **TechXtile Challenge** Level-Up finalist · **TEKNOFEST** competitor ([UGV control station](https://github.com/sbugrayy/IkaApp), AI in Aviation) · **MTA AI Specialization** capstone: [multi-sensor anomaly detection on UAV telemetry](https://github.com/sbugrayy/uav-telemetri-anomali)
- 💬 Don't feel like reading? [Chat with my AI clone](https://bugrayildirim.vercel.app/) instead

### ⚙️ Backend

- **Finance & invoicing API** *(internship · private)* — ASP.NET Core Web API serving a Flutter app: database-first EF Core on SQL Server, JWT authentication on top of ASP.NET Identity.
- **The APIs behind my AI projects** — an ASP.NET Core Minimal API with SSE streaming ([foundry-local-rag-agent](https://github.com/sbugrayy/foundry-local-rag-agent)), a FastAPI service on Hugging Face Spaces ([Portfolio](https://github.com/sbugrayy/Portfolio)) and a Dockerized MCP server ([story-to-music](https://github.com/sbugrayy/story-to-music)).

### 🧠 LLM & RAG

**[BUĞRA.AI — Portfolio](https://github.com/sbugrayy/Portfolio)** · [live ↗](https://bugrayildirim.vercel.app/)<br>
RAG-powered AI avatar: visitors chat with my digital clone instead of reading a CV. Hybrid retrieval (multilingual embeddings + BM25, fused with RRF) checked by an offline eval suite.<br>
`FastAPI` `LangChain` `ChromaDB` `Groq` `React` `Three.js`

**[foundry-local-rag-agent](https://github.com/sbugrayy/foundry-local-rag-agent)**<br>
100% on-device agentic RAG: chat with Word/PDF/Excel files with source citations and generate Word/Excel/PDF reports. Built during the Microsoft Foundry Local Summer School.<br>
`.NET 10` `ASP.NET Core` `Semantic Kernel` `Foundry Local` `SQLite`

**[story-to-music](https://github.com/sbugrayy/story-to-music)** · [demo ↗](https://huggingface.co/spaces/bugrayildirim/story-to-music)<br>
MCP server that turns Turkish stories into Suno/Udio prompts and structured lyrics with two fine-tuned mT5 models — no external API.<br>
`Python` `MCP` `mT5` `Hugging Face` `Docker`

### 👁️ Computer Vision

**[SFDDS](https://github.com/sbugrayy/SFDDS)** · 🏆 TechXtile Challenge Level-Up finalist<br>
Textile defect detection on the ZJU-Leaper dataset with YOLOv7, YOLO11 and YOLO26, exported to ONNX for real-time use.<br>
`PyTorch` `Ultralytics` `OpenCV` `ONNX`

**TURANOVA** · TEKNOFEST 2026 AI in Aviation *(private)*<br>
Autonomous image processing system: YOLO11 object detection, visual odometry and DINOv2-assisted cross-modal reference matching.<br>
`YOLO11` `DINOv2` `Visual Odometry`

**[Brain Tumor MRI Classification](https://github.com/sbugrayy/Brain-Tumor-MRI-Akbank-Bootcamp)** · Akbank Deep Learning Bootcamp<br>
Four-class brain tumor classification on ~7,000 MRI scans with a CNN baseline and EfficientNetB0 fine-tuning, explained with Grad-CAM.<br>
`TensorFlow` `Keras` `Grad-CAM`

**[Vakit](https://github.com/sbugrayy/vakit-app)**<br>
